# Third-party dependencies

The prebuilt distribution includes unmodified runtime JARs. Their original license/notice files remain within each JAR's META-INF directory. Project-specific source code is provided for your team's review and course use; follow your institution's rules regarding assisted/generated work.

| Dependency | Version | License / project |
|---|---|---|
| Apache Tomcat embedded core, Jasper, EL, annotations API | 10.1.60 | Apache-2.0; https://tomcat.apache.org/ |
| Gson | 2.11.0 | Apache-2.0; https://github.com/google/gson |
| Eclipse ECJ | 3.33.0 | EPL-2.0; https://eclipse.dev/jdt/ |
| Error Prone annotations | 2.27.0 | Apache-2.0; https://github.com/google/error-prone |

JUnit 5 and Maven plugins are build/test dependencies declared in pom.xml and are not included as runtime libraries. No external fonts, photos, icon libraries or UI templates are used. Icons are small inline SVG paths authored for this project.
